# Data Analyst: what recruiters look for

## Core skills (must have)
SQL, Excel (pivot tables, lookups, Power Query), Power BI or Tableau, Python with pandas, basic statistics, data cleaning, dashboards, reporting.

## Common tools
Power BI, Tableau, Excel, SQL databases, Google Analytics.

## Nice to have
DAX, Looker, basic ETL, Python visualisation, storytelling with data.

## Strong resume signals
Dashboards that answer a clear business question; SQL queries on a real dataset; insights that led to a decision.

## Common gaps in fresher resumes
Only Excel and no SQL; dashboards with no insight; no numbers on impact; tool names missing.

## Typical keywords
data analysis, SQL, Excel, Power BI, Tableau, dashboards, reporting, data cleaning, KPIs
