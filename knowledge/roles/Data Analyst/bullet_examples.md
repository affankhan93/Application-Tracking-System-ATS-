# Data Analyst: before and after bullet examples

These examples show patterns. The numbers are samples. Candidates must use their own real figures and never copy a number they cannot support.

Weak: Prepared reports.
Strong: Automated the weekly sales report with SQL and Power BI, saving about 6 hours of manual work each week.

Weak: Worked with Excel data.
Strong: Built an Excel model with pivot tables and lookups for 12 months of inventory data, flagging stock-outs 2 weeks earlier.

Weak: Responsible for dashboards.
Strong: Designed 8 Power BI dashboards used by 40 managers for daily decisions, replacing 3 manual reports.

Weak: Cleaned data.
Strong: Standardised 5 source files and removed duplicates, raising data accuracy to 98% before reporting.
