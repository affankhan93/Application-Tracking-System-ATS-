# Data Scientist: what recruiters look for

## Core skills (must have)
Python, pandas, NumPy, SQL, statistics and probability, scikit-learn, feature engineering, model evaluation, data visualisation, A/B testing.

## Common tools
Jupyter, Git, Matplotlib or Seaborn, XGBoost, Power BI or Tableau.

## Nice to have
Deep learning, NLP, cloud platforms (AWS, GCP, Azure), model deployment with Streamlit or FastAPI, MLOps basics.

## Strong resume signals
An end-to-end project with data cleaning, a baseline, validated results, and a deployed demo; a GitHub README that states the problem, data, method, and metrics.

## Common gaps in fresher resumes
Only notebooks and no deployment; accuracy reported without a baseline or validation method; no SQL; no business context for the model; unaware of data leakage.

## Typical keywords
data science, machine learning, predictive modelling, statistics, feature engineering, classification, regression, SQL, Python
