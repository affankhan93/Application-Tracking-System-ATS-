# Web Developer: what recruiters look for

## Core skills (must have)
HTML, CSS, JavaScript, a framework such as React, Node.js or another backend, REST APIs, responsive design, Git, SQL or NoSQL databases.

## Common tools
VS Code, Git, Chrome DevTools, npm, Figma, Postman.

## Nice to have
TypeScript, Next.js, testing with Jest, accessibility, performance tuning with Lighthouse, deployment on Vercel or Netlify.

## Strong resume signals
Live site links; responsive layouts shown on mobile and desktop; measured performance gains; reusable components.

## Common gaps in fresher resumes
No live links; no proof of responsive design; only static pages; no backend or API work.

## Typical keywords
web developer, HTML, CSS, JavaScript, React, Node.js, responsive design, REST API, frontend, backend
