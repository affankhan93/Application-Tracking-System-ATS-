# DevOps Engineer: what recruiters look for

## Core skills (must have)
Linux, Bash scripting, Git, Docker, Kubernetes, CI/CD pipelines, a cloud platform (AWS preferred), infrastructure as code, monitoring, networking basics.

## Common tools
Jenkins or GitHub Actions or GitLab CI, Terraform, Ansible, Prometheus, Grafana, Helm.

## Nice to have
Security basics, cost optimisation, service mesh, incident response.

## Strong resume signals
A pipeline that builds, tests, and deploys; infrastructure created with code; uptime or release-time numbers; an architecture diagram in the project README.

## Common gaps in fresher resumes
Tools listed with no hands-on proof; no cloud project; no automation results; no monitoring.

## Typical keywords
DevOps, CI/CD, Docker, Kubernetes, AWS, Terraform, Jenkins, Linux, monitoring, automation
