# Software Developer: what recruiters look for

## Core skills (must have)
One main language (Java, Python, or C++), data structures and algorithms, object-oriented programming, Git, REST APIs, SQL and databases, unit testing, debugging.

## Common tools
Git and GitHub, an IDE, JUnit or pytest, Postman, Docker.

## Nice to have
Spring Boot, Django or Node.js, cloud basics, design patterns, basic system design.

## Strong resume signals
Repositories with tests and a clear README; bullets showing scale, bugs fixed, or coverage gained; working in a team with code reviews.

## Common gaps in fresher resumes
No tests; only tutorial projects; no mention of algorithms for campus roles; no links to code.

## Typical keywords
software developer, Java, Python, REST API, data structures, algorithms, OOP, Git, SQL, unit testing
