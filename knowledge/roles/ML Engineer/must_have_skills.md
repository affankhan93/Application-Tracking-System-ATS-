# ML Engineer: what recruiters look for

## Core skills (must have)
Python, PyTorch or TensorFlow, deep learning, NLP or computer vision, model deployment (FastAPI, Docker), APIs, Git, cloud basics.

## Common tools
MLflow, DVC, Docker, AWS or GCP or Azure, vector databases, Hugging Face.

## Nice to have
Kubernetes, RAG and LLM tooling, model optimisation, monitoring, CI/CD for models.

## Strong resume signals
A model deployed behind an API with stated latency or throughput; experiment tracking; reproducible training.

## Common gaps in fresher resumes
Training only, with no serving or monitoring; no tests; no cloud or container experience; results with no metrics.

## Typical keywords
machine learning engineer, deep learning, PyTorch, TensorFlow, MLOps, model deployment, Docker, NLP, computer vision
